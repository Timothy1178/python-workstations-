🛠 How to install (Chrome & Edge)

  1. Download the plugin's .zip above and unzip it somewhere permanent (the browser loads it from that folder — don't delete it). If you run the workstation locally you can skip the download and use the plugins/<name>/ folder directly.
  2. Open the extensions page: chrome://extensions in Chrome, or edge://extensions in Edge.
  3. Turn on Developer mode (toggle — top right in Chrome, left sidebar in Edge).
  4. Click Load unpacked and pick the unzipped plugin folder (the one containing manifest.json).
  5. Pin the extension from the puzzle-piece menu so its button stays on the toolbar.

Updates: download the new zip, replace the folder's contents, then press the ↻ reload icon on the extensions page.
