FieldKindValue / settings

Field = how the plugin finds the input (label, then id / name / placeholder, then CSS path). Kind: plain sets the value; search-select types the search text, waits for the option list and clicks the chosen option; date fills a fixed date, today, or today ± N days in the chosen format (typed keystrokes for masked pickers, native value for <input type=date>). Checkboxes and radios take on/off, selects take the option's value or visible text, multi-selects one value per line. Drag ⋮⋮ to reorder — fields fill in this order.
