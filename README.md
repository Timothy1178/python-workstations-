# python-workstations

Local Python workstations for day-to-day work. Each workstation is a
self-contained Flask app in its own folder.

- **[qa-workstation](qa-workstation/)** — QA testing workstation: test case
  builder/runner with AI assist, CSV reader, and Copilot Studio agents with
  live chat via the Microsoft 365 Agents SDK. See its
  [README](qa-workstation/README.md) for setup.
